真实系统 · 规则与门禁

Agent 质量守护

再动手改代码。

按仓库、技术栈和变更场景加载团队工程规则；Plan、任务图和工具调用保留关键判断， 让生成过程既能追溯，也能被门禁及时打断。

  • 规则
    生成前

    匹配团队规范、风险边界和必要验证，让 Agent 先理解工程约束。

  • 证据
    执行中

    保留计划、依赖、工具动作与阻塞信息，让关键判断可以回读。

  • 门禁
    合入前

    用静态检查、测试、风险信号和人工复核决定是否完成。
