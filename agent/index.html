CONTEXT & RULES · 已复用

Context & Rules

让正确的规则，
在正确的时机进入上下文。

依据仓库、技术栈、任务类型和风险等级匹配必要约束，控制上下文范围， 避免规则缺失、信息过载和跨边界执行。

  • MATCH
    规则匹配

    让任务只加载与当前场景相关的工程要求。

  • SCOPE
    上下文边界

    区分事实、假设与历史证据，控制敏感信息暴露。

  • AUTH
    权限约束

    按任务所需授权工具和动作，超出范围时停止并确认。

已复用规则前置上下文治理最小权限
HARNESS RUNTIME · 持续运行

Harness Runtime

让 Agent 进入
可控制、可恢复的运行环境。

Harness 承接模型之外的执行责任：维护任务状态、工具权限、环境隔离、异常路径与恢复策略， 让一次执行能够安全暂停、重试和继续。

  • STATE
    状态可见

    区分进行中、完成、阻断和残余风险，避免假完成。

  • FAIL
    失败可控

    失败关闭高风险动作，并保留诊断与人工接管入口。

  • RECOVER
    执行可恢复

    在保留上下文和证据的前提下，从明确节点继续工作。

持续运行状态管理失败关闭异常恢复
