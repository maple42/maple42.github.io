实现架构

移动端自动化分层架构

业务用例只描述要完成的动作和判断。结构化 UI 优先处理稳定控件，OCR 识别多语言文字， CV 覆盖图标、Canvas 与游戏画面；当传统识别结果缺失或置信度不足时，由大模型视觉理解进行语义兜底， 最终统一交给 Airtest 执行原生设备动作，并把现场数据带回协作链路。

01

语义与识别解耦

用例保持 find、click、exists、input、assert 等业务语义，不把脚本锁死在单一识别技术上。

02

多模态能力互补

Poco / UIAutomator 读取结构化控件，OCR 处理多语言文字，CV 覆盖图标、Canvas 与游戏画面，大模型视觉负责低置信结果的语义兜底。

03

原生动作与现场记录

Airtest 统一触摸、滑动、输入、应用生命周期和截图，异常同样保留现场并回写结果。

综合案例

一套框架覆盖 App、游戏与 H5

依据历史飞书报告与本地运行记录归并。三类产品形态共用场景建模、设备编排、动作执行和数据归档， 但按照各自数据完整度分别陈述，不把截图数量当成测试成果。

案例归并

三类界面，共用一条执行与数据链

用例仍然描述登录、发布、互动、权限和结果校验等业务动作；结构化控件、OCR、CV 与视觉模型只负责适配不同界面， 最终都输出可回看的动作轨迹、截图、录屏和报告。

  • App
    Cuddmi、Mochi 与 NIMI 业务链路

    Cuddmi 覆盖 AI 角色创建与连续对话；Mochi 验证跨账号隐私隔离；NIMI 完成双机系统来电与三机语音房角色、权限校验。

  • 游戏
    骰子对战、龙虎斗与宠物玩法

    运行态素材覆盖 Canvas 动态画面中的目标定位、局面判断与结果标注，用于验证 CV / VLM 感知层，不据此推导完整通过率。

  • H5
    重点案例：Litmatch H5 8 语种本地化适配验证

    在真机上覆盖英语、泰语、越南语、印尼语、葡萄牙语、土耳其语、阿拉伯语与繁体中文；逐状态检查文本可见性、换行与截断、RTL 排版、登录态和页面跳转，而不是只确认翻译文本存在。

数据范围：App 与 H5 依据完整报告；游戏部分依据运行态截图库，只用于说明动态画面识别与标注能力。

专项应用

客户端性能与深度兼容

专项能力直接接入现有自动化场景和真机资源，采集、执行、数据与报告不再是彼此割裂的工具。

客户端性能专项

perfX × 自动化框架

性能采集跟随业务场景自动启停

自研 perfX 通过 ADB、设备端采集进程与 gRPC 通道连接 Android 真机， 再由适配层接入自动化框架，让性能数据与具体业务步骤处于同一次运行中。

  • 采集
    资源、流畅度与链路指标

    覆盖 CPU、内存、FPS / 卡顿、GPU、网络与电量，并保留过程截图。

  • 联动
    用例控制采集边界

    业务场景开始时启动采集，结束时停止并关联步骤、时间线与设备信息。

  • 交付
    功能与性能数据一起归档

    报告、测试附件与云端数据使用同一运行标识，减少人工对齐。

已接入自动化当前公开范围未公布性能收益比例
深度兼容专项

并行回归 × 真机池 × 统一报告

把设备矩阵从串行操作变成可追踪的并发任务

按系统版本、机型、分辨率、语言与网络条件生成兼容矩阵；多线程分发回归任务， 通过异步调用接收设备状态和执行结果，并与真机池租约统一管理。

  • 并发
    多线程回归与异步结果收敛

    设备执行互不阻塞；任务完成、超时和异常通过统一状态模型返回。

  • 真机
    租约、安装、恢复与释放

    自动选择可用设备并管理占用关系，支持多设备互动与远程链路长稳复验。

  • 报告
    矩阵结果与现场数据整合

    按设备、用例和失败类型汇总，截图、日志、录屏与结论可回到同一报告。

并行执行每台设备的结果和数据分别保留

业务流程 SOP 自动化

线上用户反馈从周期汇总变成持续处理

过去由客服和产品运营分别登录各应用市场后台、内部运营后台，人工收集、整理与汇总， 再按周期反馈给研发。来源分散、口径不一，紧急线上问题也容易被批次节奏延后。

新方案以开源采集能力为基础，整合内部与外部 API，建立按业务线组织的用户反馈数据底座； 日常任务每日增量同步，紧急信号单独触发通知，不再依赖人工搬运才能进入研发视野。

系统接管收集、去重、归并、打标、监测、分发和导出等重复环节， 人工主要负责业务判断、优先级决策与问题处置。

工作方式：这类落地接近 Forward-Deployed Engineering（FDE）：工程工作进入具体业务流程、连接现有系统并持续维护，而不是只交付一次性脚本。
  1. 接入
    多源反馈统一入库

    连接应用市场、内部运营后台及其他公开或授权来源，保留业务线、平台与原始出处。

  2. 同步
    每日增量更新

    按游标或时间窗口拉取新增与变更记录，完成去重、状态更新和失败补偿。

  3. 理解
    大模型归并与打标

    合并同类问题，补充主题、版本、场景与情绪标签，降低人工逐条整理成本。

  4. 预警
    正负向反馈突刺检测

    识别短时间异常波动；命中紧急发布问题规则后，第一时间通知责任团队。

  5. 交付
    多条件筛选与格式化导出

    按团队所需字段、版本、渠道、时间和标签筛选，输出各自可直接使用的数据格式。
